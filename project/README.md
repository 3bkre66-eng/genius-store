# متجر عبقري | GENIUS — نسخة تجريبية (Front-end فقط)

## محتويات المشروع
- `index.html` — هيكل الصفحة
- `style.css` — كل التنسيقات والألوان والأنيميشن
- `script.js` — منطق السلة، نافذة المنتج، الدردشة، تتبع الطلب، عداد الخصومات، وربط واتساب
- `logo.jpg` — شعار المتجر

## كيف تشغّله بـ VS Code
1. افتح مجلد المشروع كامل في VS Code: `File > Open Folder`
2. ثبّت إضافة **Live Server** (من Extensions، ابحث عن "Live Server" لـ Ritwick Dey)
3. اضغط كليك يمين على `index.html` واختر **Open with Live Server**
4. رح يفتحلك المتصفح تلقائياً على `http://127.0.0.1:5500`

## العملة
كل الأسعار بالدينار العراقي، مختصرة كـ **د.ع** بدل الدولار.

## نظام الخصومات
- أي منتج فيه خصم لازم يكون عنده `data-oldprice` (السعر الأصلي) و `data-price` (السعر بعد الخصم) — النسبة المئوية تُحسب تلقائياً بالجافاسكربت وتظهر كشارة صفراء "خصم X%".
- لإزالة الخصم عن منتج: احذف `data-oldprice` من الكرت، وشيل السطر `<span class="badge-discount">...</span>` وسطر السعر القديم `price-old`.
- لإضافة خصم لمنتج ما عنده خصم حالياً: أضف `data-oldprice="السعر_الأصلي"`، وحدّث `data-price` للسعر الجديد، وأضف شارة `<span class="badge-discount">خصم X%</span>` وسطر `price-old`.

### عداد العرض (الوقت المتبقي)
بأول `script.js` فيه:
```js
const PROMO_DURATION_SECONDS = 3 * 60 * 60; // 3 ساعات
```
غيّر الرقم لتطويل أو تقصير مدة العرض. حالياً العداد تجريبي: لما يوصل الصفر يرجع من جديد تلقائياً (loop) لأنه ما فيه تاريخ انتهاء فعلي مربوط بسيرفر. لو بدك تاريخ ونهاية حقيقية وثابتة لكل الزوار (مو تُعاد كل ما يفتح أحد الصفحة)، هذا يحتاج مثلاً تخزين "وقت البداية" بقاعدة بيانات أو سيرفر بسيط بدل الاعتماد على وقت فتح المتصفح فقط.

## واتساب
بملف `script.js`:
```js
const WHATSAPP_NUMBER = '9647742418456';
```
غيّره إذا تغيّر الرقم مستقبلاً (لازم يكون بصيغة دولية بدون + وبدون صفر بالبداية).

## المنتجات والأسعار
كل منتج بـ `index.html` هو `<div class="card">` فيه:
`data-name`, `data-desc`, `data-price`, `data-oldprice` (اختياري), `data-icon`, `data-deliver`, `data-tag`
عدّل هاي القيم مباشرة، أو أضف/احذف بطاقات كاملة لإضافة منتجات جديدة.

## الشعار
استبدل ملف `logo.jpg` بنفس الاسم لتغيير الشعار بدون ما تعدل الكود.

## ملاحظة مهمة
هذا تصميم واجهة (Front-end) فقط:
- ما فيه قاعدة بيانات ولا حسابات مستخدمين حقيقية
- ما فيه بوابة دفع فعلية
- السلة والدردشة وتتبع الطلب وعداد الخصم كلها محاكاة بصرية تعمل بالمتصفح فقط، وتُصفّر عند تحديث الصفحة
- طلب واتساب فعلي وحقيقي (يفتح wa.me برسالة جاهزة) — هذا الجزء الوحيد المتصل فعلياً بشيء خارجي

لو حبيت تحويله لمتجر حقيقي (تخزين طلبات، تسجيل دخول حقيقي، دفع إلكتروني، عداد خصم بتاريخ ثابت لكل الزوار)، هذا يحتاج خادم خلفي (backend) وقاعدة بيانات، وهو خارج نطاق هذا التصميم.
